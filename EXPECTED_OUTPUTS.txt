===============================================================================
COMMON ISSUES AND FIXES
===============================================================================

Issue 1: PIDs increment by 2 instead of 1
Fix: Don't fork twice for background jobs. Only fork once in main().

Issue 2: Multiple $ prompts printed
Fix: Ensure runcmd() exits for all code paths and main() only prints one prompt.

Issue 3: Background jobs not reaped
Fix: Call reap_background_jobs() AFTER getcmd() and BEFORE printing prompt.

Issue 4: Wrong exit status for background jobs
Fix: Properly capture and print the exit status from wait_noblock().

Issue 5: Foreground jobs treated as background
Fix: Only add jobs to jobs[] array for BACK command type.

Issue 6: Jobs command prints exited jobs
Fix: Remove jobs from jobs[] array when they are reaped.

Issue 7: Pipeline background jobs print wrong PID
Fix: For PIPE + BACK, print the PID of the first fork (left side of pipe).
